# Origem e alterações de publicação

Kit recuperado da conversa **Criar comparador PowerShell**, compartilhada em:
https://chatgpt.com/share/6ad2ab56-d808-83e9-a73b-f18e0195b55d

Os scripts e exemplos foram reconstruídos dos comandos e correções registrados na conversa. Nenhum inventário corporativo foi utilizado. O relatório demonstrativo foi regenerado com os snapshots sintéticos recuperados.

Na publicação, uma expressão substituída por `[REDACTED_SECRET]` no código compartilhado foi restaurada para ler a variável de ambiente indicada por `bearerTokenEnvironmentVariable`. Foram adicionados testes com HTTP simulado, CI em Windows PowerShell 5.1 e PowerShell 7, e este registro de origem. O teste de exclusão de senha de connection string usa um marcador sintético verificável.

O repositório de destino não tinha arquivo de licença. Esta publicação não atribui uma nova licença aos arquivos existentes.
