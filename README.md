# Downloads e ferramentas

## Comparador de deployments PowerShell

O [Deployment Audit](deployment-audit/README.md) coleta snapshots locais e compara APIs no IIS, serviços Windows, tarefas, MSMQ, certificados e configurações entre DEV, OT e PRD.

- [Documentação e comandos de uso](deployment-audit/README.md)
- [Manifesto de exemplo](deployment-audit/manifest.example.json)
- [Relatório HTML demonstrativo](deployment-audit/examples/relatorio-demo.html) — baixe o arquivo e abra no navegador.
- [Validação e limitações](deployment-audit/VALIDATION.txt)

Os exemplos são sintéticos. Inventários, configurações reais, credenciais e arquivos de ambiente não devem ser publicados neste repositório.

Os downloads existentes permanecem em `files/`.
